
# Learn With Leaders - Student Dashboard

A high-fidelity, responsive student dashboard for managing leadership programs, tracking applications, and showcasing achievements.

## Features

- **Program Discovery:** Explore world-class leadership programs with advanced filtering.
- **Application Tracking:** Visual journey tracker for your enrollment progress.
- **AI Achievement Assistant:** Real-time achievement description generation powered by Gemini API.
- **Certificates Vault:** Manage and verify your earned credentials.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop devices.

## Tech Stack

- **Framework:** React 19
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **AI Integration:** Google Gemini API (@google/genai)
- **Language:** TypeScript

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Set your environment variable: `API_KEY=your_gemini_api_key`
4. Run development server: `npm run dev`
